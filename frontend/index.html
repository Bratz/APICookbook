MCP server

                    
Connect an MCP client

                    
Any MCP client (Claude Code, Claude Desktop, Cursor…) can use these tools over streamable HTTP. No key needed; requests are rate-limited per address. If your bank needs a BaNCS access token, send it in the Accesstoken header.

                    
Endpoint
https://apicookbook.vercel.app/api/mcp

                    
Claude Code:

                    
claude mcp add --transport http bancs https://apicookbook.vercel.app/api/mcp

                    
Other clients (JSON config):

                    
{ "mcpServers": { "bancs": { "type": "http", "url": "https://apicookbook.vercel.app/api/mcp" } } }

                    
Reads run at once. A write (POST, PUT, PATCH, DELETE) is not sent: call_api returns an approval link. Open it here, approve within 10 minutes, then the client calls call_api again with {"approval_id": …} for the result.
